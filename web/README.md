# NoteMaster Web

Веб-интерфейс для системы управления заметками на Flask.

## 🚀 Запуск

```bash
cd web
pip install -r requirements.txt
python app.py
```

После запуска откройте браузер: `http://localhost:5000`

## 📋 Маршруты

| Маршрут | Метод | Описание |
|---------|-------|----------|
| `/` | GET | Главная страница (список заметок) |
| `/note/<id>` | GET | Просмотр заметки |
| `/add` | GET/POST | Создание заметки |
| `/edit/<id>` | GET/POST | Редактирование заметки |
| `/delete/<id>` | POST | Удаление заметки |

## 🎨 Дизайн

- **Тема**: светлая, минималистичная
- **Акцентные цвета**: лимонный, апельсиново-оранжевый, лаймово-зелёный
- **Анимации**: плавающие круги на фоне, hover-эффекты
- **Адаптивность**: поддержка мобильных устройств

## 🔧 Интеграция с ядром

Веб-интерфейс использует `core.NoteManager` для всех операций с заметками. Никакой прямой работы с JSON — только через API менеджера.
