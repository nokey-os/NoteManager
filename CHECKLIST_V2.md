# Checklist — NoteMaster V2 (Стабилизация)

## 📋 Сценарии тестирования

### 1. Файловая система

#### 1.1 Файл отсутствует
- [ ] `notes.json` не существует → создаётся новый
- [ ] Папка `data/` не существует → создаётся автоматически
- [ ] Нет прав на запись → ошибка с понятным сообщением

#### 1.2 Файл повреждён
- [ ] Неверный JSON синтаксис → создание backup + новый файл
- [ ] Неверная структура (не список) → создание backup + новый файл
- [ ] Отсутствуют обязательные поля в записях → пропуск записей + лог

#### 1.3 Ошибки чтения/записи
- [ ] Файл занят другим процессом → ошибка с подсказкой
- [ ] Диск заполнен → ошибка с подсказкой
- [ ] Нет прав доступа → ошибка с подсказкой

---

### 2. Валидация данных

#### 2.1 Пустой список заметок
- [ ] `get_all_notes()` → пустой список `[]`
- [ ] `update_note()` на пустом списке → `NoteManagerError`
- [ ] `delete_note()` на пустом списке → `NoteManagerError`

#### 2.2 Невалидный ID
- [ ] Поиск несуществующего UUID → `NoteNotFoundError`
- [ ] Поиск несуществующего номера → `NoteNotFoundError`
- [ ] Поиск по пустому ID → `NoteNotFoundError`
- [ ] Поиск по None → `NoteNotFoundError`

#### 2.3 Пустой title
- [ ] `create_note(title="")` → `EmptyTitleError`
- [ ] `create_note(title="   ")` → `EmptyTitleError`
- [ ] `update_note(title="")` → `EmptyTitleError`
- [ ] Web форма без title → UI ошибка

#### 2.4 Некорректные attachments
- [ ] Пустой путь → отклонён
- [ ] Несуществующий файл → отклонён (при `must_exist=True`)
- [ ] Неподдерживаемое расширение → отклонён
- [ ] Путь с опасными символами → санитизация
- [ ] Слишком большой файл (>50MB) → отклонён

---

### 3. CLI интерфейс

#### 3.1 Ошибки ввода пользователя
- [ ] `--get` без `--id` → понятная ошибка
- [ ] `--create` без `--title` → понятная ошибка
- [ ] `--update` без `--id` → понятная ошибка
- [ ] `--delete` без `--id` → понятная ошибка
- [ ] Неизвестная команда → справка

#### 3.2 Форматирование ошибок
- [ ] Ошибки пользователя → ❌ префикс
- [ ] Ошибки файловой системы → 📁 префикс
- [ ] Ошибки валидации → ⚠️ префикс
- [ ] Системные ошибки → 🔧 префикс
- [ ] Подсказки → 💡 префикс

---

### 4. Web интерфейс

#### 4.1 HTTP ошибки
- [ ] 404 на несуществующую страницу → кастомная страница
- [ ] 500 на внутреннюю ошибку → кастомная страница
- [ ] 413 на слишком большой файл → понятная ошибка

#### 4.2 Ошибки attachments
- [ ] Файл удалён из filesystem → UI "(файл не найден)"
- [ ] Попытка скачать несуществующий файл → 404 + редирект
- [ ] Вложение с битым путём → игнорирование + лог

#### 4.3 Уведомления
- [ ] Успешное создание → green alert
- [ ] Ошибка валидации → red alert
- [ ] Файл не найден → red alert
- [ ] Изменений не внесено → blue alert

---

### 5. Логирование

#### 5.1 Уровни логов
- [ ] `INFO` — создание/удаление/обновление заметок
- [ ] `WARNING` — операции с пустыми списками, пропущенные файлы
- [ ] `ERROR` — валидация, поиск, файловые ошибки
- [ ] `DEBUG` — внутренние операции (получение списка)

#### 5.2 Файлы логов
- [ ] `logs/app.log` — основные логи
- [ ] `logs/cli.log` — логи CLI
- [ ] `logs/web.log` — логи веб-сервера

---

### 6. Восстановление JSON

#### 6.1 Процесс восстановления
- [ ] Проверка существования файла
- [ ] Проверка валидности JSON
- [ ] Проверка структуры (список)
- [ ] Проверка обязательных полей
- [ ] Создание backup при необходимости
- [ ] Создание нового файла при неудаче

#### 6.2 Backup
- [ ] Имя файла: `notes_backup_YYYYMMDD_HHMMSS.json`
- [ ] Сохранение в `data/`
- [ ] Логирование пути к backup
