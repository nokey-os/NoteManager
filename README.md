# NoteManager

NoteManager — это система управления заметками, спроектированная как расширяемая платформа. Проект начинался с «ядра» — надёжного слоя для хранения и CRUD-операций с заметками в формате JSON. Сейчас в нём уже есть консольный интерфейс (CLI), а архитектура готова к добавлению веб-интерфейса, API и других сервисов.

## Основные возможности

### 🧠 Ядро (core)
- **Класс `NoteManager`** — инкапсулирует всю работу с заметками.
- **Модель `Note`** с полями:
  - `id` (UUID)
  - `title` (обязательное)
  - `content`
  - `timestamp` (ISO-формат)
  - `attachments` (список путей к файлам)
- **Хранение в JSON**:
  - данные сохраняются в `data/notes.json`
  - файл создаётся автоматически при отсутствии
  - устойчивость к битому JSON и ошибкам ввода-вывода
- **Бизнес-правила**:
  - нельзя редактировать/удалять заметки, если список пуст
  - обновление только переданных полей
  - заголовок не может быть пустым
- **Абстракция файлового доступа** — отдельный модуль `file_driver`.

### 🖥️ CLI-интерфейс
- Два режима работы:
  - **Интерактивный** — удобное текстовое меню
  - **Командная строка** — быстрые однострочные команды
- Поддерживаются все CRUD-операции:
  - `--list`, `--get --id`, `--create`, `--update --id`, `--delete --id`
- Красивый вывод таблиц и многострочный просмотр заметки
- Полная обработка ошибок и информативные сообщения

### 🧪 Тестирование
- Написаны юнит-тесты для ядра и CLI (`pytest`)
- Покрытие ключевой логики
- Используются моки для изоляции тестов

### 📝 Логирование
- Ведётся журнал операций и ошибок (файл `cli.log` + консоль)
- Уровни: INFO (создание, удаление, обновление), ERROR (ошибки)

## Быстрый старт

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/nokey-os/NoteManager.git
cd NoteManager
```

### 2. Запустите интерактивный режим CLI
```bash
python -m app.cli.cli --interactive
```

### 3. Или используйте команды
```bash
# Создать заметку
python -m app.cli.cli --create --title "Моя первая заметка" --content "Привет, мир!"

# Показать все заметки
python -m app.cli.cli --list

# Получить заметку по ID
python -m app.cli.cli --get --id <UUID>

# Обновить заголовок
python -m app.cli.cli --update --id <UUID> --title "Новый заголовок"

# Удалить заметку
python -m app.cli.cli --delete --id <UUID>
```

### 4. Запустить тесты
```bash
pytest
```

## Зависимости
Проект использует **только стандартную библиотеку Python** (кроме `pytest` для тестов).  
Это делает его лёгким и не требующим установки дополнительных пакетов для работы.
