# NoteMaster - Mini Checklist

## ✅ Обработка ошибок и краевых случаев

### 1. Файл отсутствует
- [x] JSON-файл не существует — создаётся новый
- [x] Файл загрузок отсутствует — создаётся автоматически
- **Тест**: `test_load_empty_from_nonexistent_file`

### 2. Файл повреждён
- [x] Невалидный JSON — попытка восстановления
- [x] Неверная структура (не список) — создание нового файла
- [x] Бэкап повреждённого файла перед восстановлением
- **Тест**: `test_recovery_manager_detects_invalid_json`
- **Тест**: `test_recovery_manager_detects_wrong_structure`

### 3. Пустой список заметок
- [x] Попытка обновления — ошибка `EmptyListError`
- [x] Попытка удаления — ошибка `EmptyListError`
- [x] Получение списка — возвращает пустой список (ок)
- **Тест**: `test_update_note_empty_list_raises`
- **Тест**: `test_delete_note_empty_list_raises`

### 4. Некорректный ID
- [x] Заметка не найдена — `NoteNotFoundError`
- [x] Частичный UUID поддерживается (CLI)
- [x] Порядковый номер поддерживается (CLI)
- **Тест**: `test_get_note_by_id_not_found`
- **Тест**: `test_delete_note_not_found`

### 5. Пустой заголовок
- [x] Создание с пустым заголовком — `ValidationError`
- [x] Создание с пробелами — `ValidationError`
- [x] Обновление на пустой — `ValidationError`
- **Тест**: `test_create_note_empty_title_raises`
- **Тест**: `test_update_note_empty_title_raises`

### 6. Ошибки чтения/записи
- [x] Отсутствие прав доступа — `FileSystemError`
- [x] Недоступность диска — логирование ошибки
- [x] Файл заблокирован — обработка исключения
- **Логирование**: INFO/WARNING/ERROR уровни

### 7. Некорректные attachments
- [x] Невалидное расширение — файл пропускается с предупреждением
- [x] Путь не существует — предупреждение (не ошибка)
- [x] Файл удалён — UI показывает статус "(файл не найден)"
- **Тест**: `test_file_validator_rejects_invalid_extension`

### 8. Попытка удаления несуществующей заметки
- [x] CLI — понятное сообщение с подсказкой
- [x] Web — редирект на главную с flash-сообщением
- **Тест**: `test_delete_note_not_found`

### 9. Ошибки CLI-ввода
- [x] Отсутствует --id для get/update/delete
- [x] Отсутствует --title для create
- [x] Интерактивный режим — валидация ввода
- **Код**: `main()` с проверкой аргументов

### 10. Ошибки HTTP-запросов
- [x] 404 — обработчик возвращает шаблон с ошибкой
- [x] 500 — обработчик логирует и показывает сообщение
- [x] Исключения — глобальный обработчик
- **Код**: `@app.errorhandler(404/500/Exception)`

## 🧪 Запуск тестов

```bash
# Установить зависимости
pip install pytest

# Запустить тесты
pytest tests/test_core.py -v

# Запустить с покрытием
pytest tests/test_core.py -v --cov=core
```

## 📝 Примеры использования

### Создание заметки
```bash
python -m app.cli.cli --create --title "Моя заметка" --content "Текст"
```

### Просмотр всех заметок
```bash
python -m app.cli.cli --list
```

### Запуск Web
```bash
python web/app.py
# Открываем http://localhost:5000
```
